Designed for people, not bloat

Our design goals for the first public release.

🪶

Runs light

Built to feel fast on a 2 GB RAM PC, with a low-end mode that trades effects for speed.

🛡️

Secure by design

Every app lives in its own sandbox on a memory-safe kernel, so one bad app cannot take over the system.

♻️

Self-healing

A read-only system with A/B updates that roll back automatically if anything goes wrong.

🧹

Offline cleaner

A recovery mode that scans before the main system loads, so threats have nowhere to hide.

💎

Cosmic Glass UI

A liquid glass interface with fluid animations, made to feel alive.

⚡

Fast networking

A modern network stack tuned for low latency and steady throughput.

Questions

Quick answers about MintBug OS.

Is MintBug based on Linux?

No. The kernel and every layer above it are written from scratch.

When can I use it?

MintBug is under development. Stay tuned for the first alpha.

Who is building it?

Gentix Science, a team of teens in India. Developed by teens, grown by teens.

Will it run on old PCs?

That is the goal. We are designing it to run on PCs with as little as 2 GB of RAM.

Will it run Windows apps?

We are exploring compatibility options. For now the focus is the core system.
